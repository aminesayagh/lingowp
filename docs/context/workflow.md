- Plugin initialization
  - Load the plugin autoloader
  - Load Action Scheduler
  - Create or upgrade the database structure
    - Validate that WordPress parent tables use InnoDB
    - Create the source tables
    - Create the translation tables
    - Validate the foreign keys
  - Create the default settings
  - Register the language rewrite rules
  - Schedule the initial discovery scan
  - Register the front-end, admin, REST API, and lifecycle hooks
- Data injection process
  - Initial discovery
    - Scan existing posts in background batches
    - Scan existing terms in background batches
  - Live discovery
    - Detect post save
    - Detect metadata add, update, or deletion
    - Detect term creation or update
  - Post
    - Extract the title and excerpt from the database
    - Split the post content into translatable units
    - Normalize and hash each source text
    - Insert missing source records into the database
    - Carry existing translations after an edit
    - Mark carried translations as To review
    - Remove source records that no longer exist
  - Terms
    - Extract the name and description
    - Insert or update the source records
    - Remove obsolete source records
  - Meta
    - Select the allowed metadata keys
    - Extract scalar values and nested text values
    - Store the path of each nested value
    - Insert or update the source records
    - Remove deleted values
  - Static text
    - Capture text from gettext hooks
    - Capture plural messages from the _n hooks (singular and plural forms)
    - Exclude text already owned by posts, terms, meta, or HTML
    - Buffer newly discovered text
    - Schedule a background insertion job
    - Insert missing source records
    - Link the plural original to its singular anchor
  - Raw HTML
    - Start the HTML marking mode from a source-language page
    - Capture the final page output
    - Extract translatable HTML units and their selectors
    - Exclude text already owned by another content type
    - Insert missing source records
  - Options
    - Read the allowlisted WordPress options
      - Site title and tagline
      - Theme customizer text (theme mods)
      - Legacy widget text
      - Extend the allowlist with the translangs_option_paths filter
    - Extract scalar or nested text values
    - Skip values that are not translatable (markup, urls, emails, colours, numbers)
    - Insert missing source records
  - Common rules
    - Store source text independently from languages
    - Skip text that is not translatable (empty, numbers, dates, special characters, urls, emails, filenames)
    - Avoid duplicated source records
    - Create translation records only when a translation is saved
- Front-end rendering
  - Validate the request
    - Allow normal front-end page requests
    - Ignore admin, REST, AJAX, cron, feeds, and static assets
  - Get the current language
    - Detect the language from the URL
    - Detect the preview language
    - Detect the saved language cookie
    - Detect the browser language
    - Fall back to the default language
  - Preload translations for the current page
  - Post
    - Use hooks to detect content requested from WordPress
    - Translate the title and excerpt using their text hashes
    - Split the content into the same units used during extraction
    - Query and replace each translated unit
  - Terms
    - Detect terms returned by WordPress
    - Translate the name and description
  - Meta
    - Detect requests for allowed metadata keys
    - Query the translation using the post, key, and value location
    - Return the original value when no translation exists
  - Static text
    - Detect gettext calls
    - Query using the text domain, context, and original text
    - Return the translated text
    - For plural calls, pick the form for the count using the language's plural rule
    - Return the original form when the chosen form is missing
  - Raw HTML
    - Capture the final HTML response
    - Load the HTML translation map
    - Replace matching HTML units
  - Options
    - Replace the site title and tagline at the bloginfo display layer
    - Replace other option text (theme mods, widgets) in the final HTML output pass
    - Keep the stored option value untouched, so business logic gets the original
  - Rewrite internal links for the current language
  - Generate the language switcher
  - Generate canonical and hreflang links
  - Return the original text when a translation is missing
  - Cache loaded translations during the request
- Admin board
  - Settings
    - Configure the target languages
    - Configure the default-language URL prefix
    - Configure cookie language detection
    - Configure browser language detection
    - Refresh rewrite rules after routing changes
  - Load the available languages and content areas
  - Display translation progress and counts
  - Filter by content area, language, status, origin, or search text
  - Display strings grouped by their content owner
  - Translation editing
    - Save one translation
    - Edit each plural form for a plural message (one box per language plural form)
    - Save translations for several languages
    - Copy a translation from another language
    - Validate formatting placeholders
    - Detect concurrent editing conflicts
    - Mark translations as Machine, To review, or Done
    - Delete a translation
  - Duplicate management
    - Find matching source text
    - Apply a translation to selected duplicates
  - Do not translate
    - Ignore a source record
    - Delete its translations
    - Restore ignored source records
  - Discovery
    - Rescan one content owner
    - Rescan the complete website
    - Scan allowed WordPress options
  - Preview
    - Build the translated front-end URL
    - Highlight the selected source on the page
  - Import and export
    - Export sources and translations to CSV
    - Validate an import before saving
    - Import translations to review
  - Display database health information
- Cleanup process
  - Remove obsolete records during post, meta, and term reconciliation
  - Use foreign-key cleanup when posts, terms, or options are deleted
  - Flush rewrite rules when the plugin is deactivated
  - Drop translation tables before source tables during uninstall
  - Delete plugin settings during uninstall
