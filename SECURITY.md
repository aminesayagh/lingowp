# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- **Email:** contact@masayagh.com
- **Or GitHub:** the repository's *Security* tab → *Report a vulnerability*
  (private advisory).

Include the version, what an attacker can do, and the steps to reproduce.
You will get an answer within a few days. Once a fix is released, you will
be credited in the release notes if you wish.

## Supported versions

Only the latest release receives security fixes. Please update before
reporting, and check that the issue still happens.

## Scope

The Linvara plugin code in this repository. Linvara Cloud
(`cloud.lingowp.com`) is a separate service; issues with it can be reported
at the same address.
